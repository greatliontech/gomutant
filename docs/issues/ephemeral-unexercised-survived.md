# ephemeral prints SURVIVED for an edit the oracle never links

`gomutant ephemeral` on an edit whose file belongs to a package the
named oracle test binary never links buckets the mutant unexercised
and renders SURVIVED without running the test — vacuous evidence
that reads exactly like a real survivor verdict, so a probe author
citing it inherits a false claim. Demonstrated 2026-08-29 in
gofresh's chunk-106 review: an UNPARSABLE mutation of a fixture-only
package (`closure/fixtures/scalarglobalwrite`, `var Count int =
@@@`) printed SURVIVED with the closure package's observability test
as the named oracle — the fixture is analyzed as data by that test,
never compiled into its binary, so nothing could have run, and even
a syntax error goes unnoticed.

Resolution shape: an edit outside the oracle's linked source set
refuses loudly — name the fact ("the oracle never compiles this
file; no verdict") — instead of rendering a survivor verdict; a
parse/build failure of the edited file refuses on that ground first.
