# The run's serve path keys prebuilt views by the current oracle's posture

The run builds its decision views under the package-process posture
of the target's CURRENT derived oracle and hands them to the record's
judgment as the prebuilt set, while the judgment's supplementary
fallback keys by the RECORDED oracle's posture; when the two differ
the record is judged over a view built under the other posture. The
disagreement reaches only the stale-attribution text (the serve's
freshness verdicts read the same subjects under both postures'
captures), so no verdict moves; the collapse is one posture rule for
the serve path and the judgment — the finding's — or the run passing
both postures' sets.
