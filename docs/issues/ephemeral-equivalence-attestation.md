EQUIVALENT (chunk 103's union-vs-dispatch, chunk 132's
defense-in-depth nil guard) is recorded today only as a
commit-message paragraph — not greppable beside the findings, and
indistinguishable at a glance from an untested survivor. The ask

"<rationale>"` records the probe's edit hash and rationale in the
findings document as an equivalence row, giving ephemeral
equivalences the same durable, auditable home campaign attestations
already have.
