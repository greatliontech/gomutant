# A knob's terse clause serves both faces from one document line

REQ-mcp-guidance renders every schema description and flag usage
string from the guidance document's knob text — the first clause up to
its first semicolon outside parentheses — and one knob line documents
both faces, so a clause whose parenthesis names the other face reaches
each face carrying the other's prose: the batch knob's "on the cli a
JSON file … or - for stdin" serves on mcp, the timeout knobs' "on mcp
omitted means 300 seconds" serves on the cli, `reattest`'s "with
attest" names the sibling by its shared spelling. The two-surfaces
doctrine wants each face's prose written for its reader. Either the
document marks a per-face terse clause, or the clause rule stops at a
parenthesis naming the other face, or the cross-face prose is accepted
as the price of one line — a surface-doctrine judgment stipulator's
issue of the same name puts to the same chunk.
