# A render-bound expiry discards a committed run's whole structured response

When the post-commit render bound elapses on the structured face — a
changed-ref run whose per-row survivor cut crosses the bound, the shape
the bound's own doc names — the run tool returns the error and the
protocol layer discards the typed response: the rows, the summary
(counts, run identity, postures, unreached roster), the delta, the
machine-local signpost, the document path are lost; only what rides
the error text survives (the persisted drop and promotion, the sheds,
the analysis payloads). One boundary earlier the same face does the
opposite: a cancellation after measurement began returns a succeeding
result carrying the banked state, precisely so nothing the protocol
layer discards is lost. The render bound wants the same shape — the
rows built so far banked, the bound named in the result's exit — so a
committed run's response is never an error text alone.
